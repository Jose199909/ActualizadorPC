# Cómo contribuir

[English version](CONTRIBUTING.en.md)

Gracias por tu interés en mejorar ActualizadorPC.

## Antes de comenzar

1. Revisa las incidencias abiertas para evitar duplicados.
2. Describe claramente el problema o la mejora propuesta.
3. Mantén los cambios centrados en una sola finalidad.

## Probar los cambios

- Utiliza Windows 11 con Windows PowerShell 5.1 y `winget`.
- Comprueba la búsqueda sin seleccionar actualizaciones innecesarias.
- Verifica que la interfaz continúe respondiendo durante la operación.
- Confirma que los mensajes mostrados sean claros y estén en español.
- Nunca incluyas contraseñas, tokens, datos personales ni archivos generados localmente.

## Enviar una contribución

1. Crea una rama para tu cambio.
2. Realiza cambios pequeños y fáciles de revisar.
3. Explica qué cambiaste, por qué y cómo lo probaste.
4. Abre una solicitud de cambios hacia la rama `main`.
