# Security Policy

[Versión en español](SECURITY.md)

## Supported versions

The latest version published on the `main` branch is the supported version.

## Reporting a vulnerability

Do not publish sensitive information or details that would allow a vulnerability to be exploited in a public issue. Contact the repository owner privately through their GitHub profile and include:

- A clear description of the problem.
- Steps to reproduce it.
- The Windows and PowerShell versions used.
- The potential impact.
- A suggested fix, if available.

Do not include passwords, tokens, personal data, or logs containing sensitive information.
