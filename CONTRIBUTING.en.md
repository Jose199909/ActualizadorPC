# Contributing

[Versión en español](CONTRIBUTING.md)

Thank you for your interest in improving ActualizadorPC.

## Before you begin

1. Review open issues to avoid duplicates.
2. Clearly describe the problem or proposed improvement.
3. Keep each change focused on a single purpose.

## Testing changes

- Use Windows 11 with Windows PowerShell 5.1 and `winget`.
- Test scanning without selecting unnecessary updates.
- Verify that the interface remains responsive during the operation.
- Confirm that messages shown to users are clear.
- Never include passwords, tokens, personal data, or locally generated files.

## Submitting a contribution

1. Create a branch for your change.
2. Make small changes that are easy to review.
3. Explain what you changed, why, and how you tested it.
4. Open a pull request targeting the `main` branch.
