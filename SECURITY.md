# Política de seguridad

[English version](SECURITY.en.md)

## Versiones compatibles

La versión más reciente publicada en la rama `main` es la versión compatible.

## Informar de una vulnerabilidad

No publiques información sensible ni detalles que permitan explotar una vulnerabilidad en una incidencia pública. Comunícate de forma privada con el responsable del repositorio mediante su perfil de GitHub e incluye:

- Una descripción clara del problema.
- Los pasos necesarios para reproducirlo.
- La versión de Windows y PowerShell utilizadas.
- El posible impacto.
- Una propuesta de solución, si la tienes.

Evita incluir contraseñas, tokens, datos personales o registros con información sensible.
